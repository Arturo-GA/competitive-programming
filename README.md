# Programación competitiva

Mis soluciones en C++ a problemas de **Codeforces**, **CSES Problem Set** y el **AtCoder Educational DP Contest**.

- Codeforces: [Art_Gtz](https://codeforces.com/profile/Art_Gtz)
- Lenguaje: C++ (GNU C++20)

## Estructura

```
codeforces/   75 archivos (74 problemas)
cses/         12 problemas
atcoder-dp/   9 problemas
```

## Compilar y ejecutar

```bash
g++ -std=c++20 -O2 -o sol codeforces/4A_Watermelon.cpp
./sol < input.txt
```
